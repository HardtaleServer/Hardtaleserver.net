What is now implemented in app
1) Staff role styling hierarchy
- Role-specific gradients now apply to staff labels/ranks/badges for Dev/Admin/Mod/Helper.

2) Linked/Unlinked profile badge behavior
- Profile cards now always show a link-state badge:
  - 🔓 Unlinked when not linked
  - 🔗 Linked when linked
- This replaces itself dynamically by linked state.

3) Linked/Unlinked achievements
- Added dynamic achievements on API side:
  - unlinked_state (🔓 Unlinked)
  - linked_state (🔗 Linked)
- They reflect current account link state in achievement cards.

4) Existing link milestone preserved
- linking_up achievement still exists for successful /link completion.
